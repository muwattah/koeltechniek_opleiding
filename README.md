# Koeltechniek Opleiding \u2013 Interactieve Quiz

Interactieve web-quiz voor **Module 1: Basis Koeltechniek** (Odisee).

## Inhoud
- 21 meerkeuzevragen
- Categorie\u00ebn: geschiedenis, warmtepomp, warmteoverdracht, koelcyclus, log p,h-diagram, oververhitting/onderkoeling, COP/EER
- Directe feedback + uitleg na elke vraag
- Score + overzicht van alle antwoorden
- Volledig responsive (mobiel + desktop)

## Gebruik
Open gewoon `index.html` in een browser, of host de map op GitHub Pages / Netlify / Vercel.

### Lokaal starten
```bash
# Geen build nodig \u2013 pure HTML/CSS/JS
open index.html
```

## Technologie
- Vanilla HTML5, CSS3 & JavaScript
- Geen frameworks of dependencies
